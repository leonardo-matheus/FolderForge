# FolderForge Documentation

This folder contains the GitHub Pages landing page for FolderForge.

## Structure

```
docs/
├── index.html          # Main landing page
├── assets/
│   ├── logo.svg        # Project logo
│   ├── favicon.svg     # Browser favicon
│   ├── og-image.png    # Social media preview (create manually)
│   └── demo.gif        # Demo animation (create manually)
└── README.md           # This file
```

## Hosting on GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings** → **Pages**
3. Select **Source**: Deploy from a branch
4. Select **Branch**: `main` and folder `/docs`
5. Click **Save**

Your site will be available at: `https://your-username.github.io/FolderForge`

## Customization

- Replace `seu-usuario` with your GitHub username in all links
- Add a `demo.gif` showing the tool in action
- Create an `og-image.png` (1200x630px) for social media previews
